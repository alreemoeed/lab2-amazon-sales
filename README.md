# Machine Learning Lab 2

## Dataset Summary
This project uses an Amazon-style e-commerce sales dataset in CSV format.
The dataset contains information about product prices, discounts, quantities sold,
customer regions, ratings, and total revenue.

The objective of this project is to predict the total revenue of an order based on
available sales and customer-related features.
This is a regression problem since the target variable (total_revenue) is a
continuous numerical value.
